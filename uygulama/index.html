Proje Kontrol

Telefonda projelerinizi, durumlarını, yapılacakları ve sahadaki sürümleri görürsünüz. Veriler özel GitHub repolarınızdan okunur; bunun için bir kez erişim anahtarı girilir ve yalnızca bu telefonda saklanır.

  1. github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: proje-kontrol ve proje-kontrol-veri
  3. Permissions → Contents: proje-kontrol için Read, proje-kontrol-veri için Read and write
